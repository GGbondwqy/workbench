# 学途工作台 (Study Workbench)

本地优先的个人学习与求职管理工作台：**任务规划 · 目标里程碑 · 知识库 · 雅思备考 · 研究生学业 · 就业求职 · 力扣刷题**，一站式跑在 127.0.0.1。

- 💻 **零依赖**：Python 3.10+ 标准库 + 原生 ES Modules 前端，无数据库服务、无构建步骤，克隆即用
- 🔒 **本地私有**：所有数据都在本机 `data/` 目录（SQLite 单文件），不上传任何服务器
- 🤖 **AI 可选**：OpenAI 兼容接口（DeepSeek / Qwen / 各类中转站），配置了全面升级；**不配置也能用**——一切 AI 功能都有本地降级形态
- 🌗 **浅色 / 深色**主题一键切换，自动记住

## 快速开始

```bash
git clone https://github.com/GGbondwqy/workbench.git
cd workbench
python server.py        # Windows 也可双击 start.bat
```

打开 `http://127.0.0.1:8787/`（首次启动自动建库建索引，约 10-30 秒）。改端口/不自动开浏览器：`python server.py --port 9000 --no-browser`。

可选增强：

| 组件 | 作用 | 不装会怎样 |
|---|---|---|
| Python 3.10+ | 唯一硬性要求 | — |
| `pip install pypdf` | PDF 全文抽取（文献/课程资料/PDF 上传入库） | PDF 只能按标题处理 |
| AI 档案（设置页配置） | 问答/出题/判分/建议全面升级 | 本地规则降级，功能不消失 |
| 知识库内容 | 见下文「内容版权」 | 对应库为空，其余板块不受影响 |

## 功能总览

| 页面 | 核心能力 |
|---|---|
| 📊 工作台 | 今日任务（增改删/完成）、目标里程碑进度、八股阅读速览 |
| 🎯 目标 | 长期目标、五步里程碑、进度自动推进、归档 |
| 📚 资料库 | 多知识库切换、全文检索、wiki 双链、知识图谱、四入口入库、收藏夹 |
| 🇬🇧 雅思 | 刷题（内置题库+导入+新闻出题）、真题错题、口语（话题库+录音）、写作、模考设置 |
| 🎓 研究生 | 课程学习（绑文件夹/问 AI/AI 考我）、文献阅读、导师与组会、小论文、知识库 |
| 💼 就业 | 八股学习计划、项目学习、实习投递看板、面经库、投递导航 |
| 🧮 力扣 | leetcode.cn 进度同步、本地刷题文件夹、问 AI、AI 考我（记忆曲线复习） |
| 💰 AI 用量 | 每次调用的本地记账：token、缓存命中、三档计价、趋势与明细 |
| ⚙️ 设置 | AI 多档案（拉模型列表/连通测试/增删）、知识库路径、力扣账号、主题 |

每个页面逐卡说明见 **[docs/USAGE.md](docs/USAGE.md)**；二次开发（架构与红线、新增模块、测试、踩坑清单）见 **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**。

## 配置（data/config.json，首次运行自动生成）

```jsonc
{
  "ai": {
    "active": "deepseek",            // 启用哪个档案；null = 不用 AI（本地降级）
    "providers": [                   // OpenAI 兼容格式，可配多个、随时切换
      { "name": "deepseek", "base_url": "https://api.deepseek.com/v1",
        "api_key": "sk-...", "model": "deepseek-chat", "enabled": true }
    ]
  },
  "kb": { "path": "D:/path/to/kb" }, // 知识库根目录（仓库外，只读挂载）
  "leetcode": { "username": "...", "folder": "D:/path/to/leetcode" }
}
```

推荐在**设置页**里改配置（热生效、密钥不回显），不必手编 JSON。

## 内容版权（重要）

- 本仓库**只含代码框架与原创内置内容**（雅思仿真题、口语写作题库、投递导航链接清单等均为原创，随软件分发）；
- 第三方版权内容（收集的题库、外部知识库文章等）**永远不进仓库**——通过配置把知识库路径指向仓库外的本地文件夹挂载使用；运行时数据全部落在 gitignore 的 `data/`；
- 请同样遵守：不要把第三方版权内容提交进你 fork 的仓库。

## 数据与隐私

- 数据只有一份：本机 `data/workbench.db`，复制即备份；
- AI 密钥只存在本机 `data/config.json`（gitignore），页面回显永不泄露密钥；
- 服务只绑定 `127.0.0.1`，静态服务带路径穿越防护；单人使用，无账号无登录。
