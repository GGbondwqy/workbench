# 使用手册 · 页面功能详解

> 侧栏共 9 个导航页 + 1 个隐藏页（图谱全屏），多 Tab 页面在页顶切换。所有数据存本机；AI 功能未配置时自动走本地降级，界面会标注「AI 未配置」。
>
> 快速开始见 [README](../README.md)；二次开发见 [DEVELOPMENT.md](DEVELOPMENT.md)。

---

## 📊 工作台（首页）

每天从这里开始。

- **今日任务**：手动添加任务（标题/预估分钟/关联目标），可改名、可删除、点击完成；课程作业、导师任务可一键「转为今日待办」；完成的任务自动推进关联目标的里程碑进度。
- **目标进度**：各目标的里程碑完成度一目了然，点击进目标页。
- **八股速览**：显示八股阅读计划的剩余篇数与今日已读，直达阅读页。

> 早期版本的「今日三件事 AI 建议」已按使用反馈移除——任务自己加，工作台只做展示与快速操作。

## 🎯 目标

- **目标卡片**：标题、说明、截止日、颜色标记；支持**归档**（做完收起，可恢复/彻底删除）与删除。
- **五步里程碑**：每个目标可拆里程碑，勾选即推进进度条；任务完成、八股/刷题打卡也会自动推进关联目标。
- 进度 = 里程碑勾选 + 关联任务/打卡的加权结果，无需手填。

## 📚 资料库

Wiki 形态的个人知识库，支持多库。

- **知识库切换**：页顶切换条（全部 / 各分库，带篇数）。检索与提问只在所选库内进行；选「全部」时跨库检索并标注来源库。
- **全文检索**：输入关键词即时搜索，结果高亮命中片段，点开即读。
- **阅读视图**：双链 `[[文章]]` 可点击跳转；文末显示**反向链接**（谁引用了本篇）；可直接就本文提问（AI 作答并自动存为知识卡片）；可写库的文章可编辑、可删除。
- **知识图谱**：小图嵌在页内，点「全屏」进入独占页（见下文隐藏页）。
- **四入口入库**：粘贴 Markdown / 上传 md·txt·docx·pdf 文件 / 输入 URL 自动抓正文 / 指定文件夹自动扫描。PDF 全文解析需可选组件 `pypdf`。
- **收藏夹**：收集站外链接（标题+URL），每条可删除。

## 🇬🇧 雅思（五个子 Tab）

### ✍️ 刷题
- 内置原创题库（听力/阅读仿真题），做题、自动判分、错题自动进错题本；
- **📰 新闻出题**（纯脚本零 AI）：从 BBC Learning English / BBC News / VOA 拉最新文章，程序自动生成挖空与选词题，真音频自动下载到本机播放；
- 题库支持导入（JSON 格式，见 DEVELOPMENT 的题库格式说明）。

### 📈 真题与错题
- 做过的题组成绩单，错题本分列展示、可删除，点击回看原题与解析。

### 🗣 口语
- **内置原创话题库**：Part 1 / Part 2 / Part 3 分开陈列，Part 2 配 cue card + 范文 + 亮点词组；
- **每日话题**：按日期从话题池轮换，每天一个常考话题；
- **我的版本**：每个话题可从范文改写或自由作答，存本机；支持 **🎤 录音**（回放/删除，浏览器需允许麦克风）；
- **计时练习**：1 分钟准备 + 2 分钟作答倒计时。

### 📝 写作
- **每日任务**：Task 1 / Task 2 按日期轮换；
- **题库**：原创 prompt + 结构要点 + 范文 + 词组；
- **我的作文**：编辑区实时词数统计（Task 2 ≥250 / Task 1 ≥150），可计时（40/20 分钟），存本机。

### 🗓 模考与设置
- 考试日倒计时、考试安排说明卡（机考说明与报名入口）；
- 题库管理与模考记录。

## 🎓 研究生（五个子 Tab）

### 📖 知识库
与资料库同能力的独立分库（研究生笔记），wiki 双链/检索/图谱齐全。

### 📅 课程学习
- **课程列表**：新建课程 = 选一个本机文件夹 + 命名（项目式一步建完）；上课时间选填，填了自动进课表联动；
- **课程详情**（点课程卡进入）：
  - **文件区**：自动列出文件夹里的课件（PPT/Word/PDF/笔记），点击用系统默认程序打开；可标记「已复习」并看进度条；
  - **作业管理**：标题/截止日/状态/备注/关联文件，临期与过期高亮，一键转今日待办；
  - **🤖 问 AI**：基于课程文件夹资料回答并标注来源文件，资料不足时 AI 自身知识补充（标注「补充」）；
  - **🎯 AI 考我**：AI 根据课程资料出简答题，逐题作答、AI 判分（过/含糊/没过+点评）；
  - **学习助手进驻**：建课时自动把「学习助手」技能装进课程文件夹（供 ZCode 等 AI 编程助手使用，仅当你说「我要学习了/考考我」才启用，写报告赶作业不打扰）。

### 📚 文献阅读
- 文献条目（标题/作者/年份/状态）与笔记；配合 Zotero 导出 BBT 文件可导入；文献可删、笔记可删。

### 👨‍🏫 导师与组会
- **导师任务池**：临时任务先收集，一键转当日待办；可删除；
- **组会记录**：每次组会内容与待办归档，可删除。

### 📄 小论文
选题 → 文献 → 实验 → 初稿 → 投稿五步里程碑，可关联文献。

## 💼 就业（五个子 Tab）

### 📖 八股学习
- **每日计划**：知识库文章按栏目轮转排每日阅读，读完打勾（可撤销）；
- **找文章**：不想跟计划走时自由搜索——全文搜索 + 按栏目/已读未读筛选；
- **问答窗口**：不懂就问，AI 回答并注明参考文章，问答自动存为知识卡片；
- **开始复习**：针对你问过的知识卡片出题复习，按记忆曲线（1/2/4/7/15/30 天）调度，答对推进、答错重来；
- **知识图谱**：分层浏览（栏目 → 主题组 → 文章，每层 ≤10 节点），全屏页可拖拽缩放，支持手动增删连线。

### 🛠 项目学习
- 项目卡片（名称/状态/里程碑）；每项目可记**技术栈清单、亮点难点笔记、面试问答准备**（"面试官会怎么问"+ 我的回答版本）；
- **简历管理**：版本列表、修改备注、关联投递批次；条目均可删除，项目可归档。

### 🏢 实习准备
- **面试日程**：时间+公司+轮次，临近自动出现在工作台；
- **投递看板**：七列状态流转（已投递→笔试→一面→二面→HR面→Offer/已结束），卡片可推进、可删除（轨迹随行删）；
- **面试复盘**：每场记录被问问题与改进点，可删除；
- **Offer 对比器**：薪资/方向/评分多 Offer 并排比较。

### 📚 面经库
- 与资料库同能力的面经分库（粘贴/上传/URL 抓取/文件夹扫描四入口），检索、图谱、双链齐全，文章可删除；
- **⭐ 快速收藏**：站外面经链接收藏，每条可删除。

### 🚀 投递导航
- **招聘平台**与**公司官网**两组官方直达链接（新窗口打开），清单随软件内置。

## 🧮 力扣

- **🧮 力扣同步**：填用户名拉公开进度（通过数/难度分布）；填 Cookie 可同步最近 AC 到刷题记录（同日同题去重，Cookie 过期有明确提示）；
- **手动打卡**：不配同步也能记题（题目名+题型）；
- **📚 本地刷题文件夹**：绑定本机刷题学习文件夹（含 learning/ 笔记体系）后，自动读取知识卡数、章节数与待复习数，作为问 AI 与复习的资料源；
- **💬 问 AI**：基于本地学习笔记与文件夹资料回答刷题问题，标注来源卡片编号；资料不足时 AI 自身知识补充；
- **📝 AI 考我**：从本地复习清单挑**到期卡片**逐题作答，AI 判分（过/含糊/没过+点评），结果**回写本地复习清单**推进记忆曲线（答对进阶段/答错重置/含糊标薄弱）；未接 AI 时对照卡片自评打卡。

## 💰 AI 用量

- **本地自动记账**：软件里每次 AI 调用（聊天/语义向量）自动记录模型、输入/输出 token、缓存命中与功能用途，不依赖服务商账单接口；
- **三档计价**：未命中输入×全价 + 缓存命中×折扣价 + 输出×输出价；内置参考价，**单价可在页面直接改**，改完全部历史重算；
- **看板**：今日/本月汇总、近 30 天逐日趋势、按模型明细、按功能明细。

## ⚙️ 设置

- **AI 助手**：多档案管理（新增/删除/切换启用）；填好地址+密钥后**一键拉取可用模型列表**下拉选择；每档附**连通测试**按钮；删除使用中的档案自动回落本地规则；
- **知识库路径**：指向仓库外的本地文件夹（只读挂载），保存后自动扫描；
- **力扣**：用户名 / Cookie / 本地刷题文件夹，保存即同步；
- **外观与数据**：主题切换；备份 = 复制 `data/workbench.db`。

## 隐藏页：知识图谱全屏（#/graph）

- 从资料库/八股页的「全屏」进入，独占整页；
- 拖拽平移、滚轮缩放、搜索定位、点节点开文章；
- **分层浏览**：栏目层 → 主题组层 → 文章层逐层下钻，每层节点数自动控制在 ~10 以内，面包屑随时返回。

## 三条通用约定

1. **删除一律有确认**：所有 ✕ 删除按钮都会弹确认框，确认后物理删除（八股正库为只读挂载不可删）。
2. **AI 未配置也能用**：问答给最相关原文段落、考我变自测自评、建议走本地规则——界面上有「AI 未配置」角标提示。
3. **数据只在 `data/`**：换电脑 = 拷走 `data/` 目录（敏感配置在其中的 config.json，注意保管）。
